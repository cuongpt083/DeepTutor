# Page — Check

Quiz and solve. Stem + ChoiceCards are the stage and the band at once.

## Emphasis

- One item visible.
- Options 2–4 ChoiceCards. More → PickerSheet.
- Progress “Câu 2 / 5” in the rail, not a chart.
- Solve: one StepCard at a time. Chips: Gợi ý · Tôi tự làm · Giải thích bước.

## Feedback

Correct = ember rule + tick + speech.  
Wrong = danger rule + dash + speech. No shake-the-phone.

## Anti-patterns

Rainbow A/B/C/D blocks. Confetti. Timer pressure unless a teacher later adds it.
