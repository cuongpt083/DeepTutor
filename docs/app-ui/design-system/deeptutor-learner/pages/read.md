# Page — Read

ArtifactStage owns the middle (page). Character shrinks to rail still on mobile.

## Emphasis

- Page number in mono.
- Citation chip seeks; tutor speaks the highlighted region.
- Band defaults: Giải thích trang này · Đặt 3 câu · Trang sau.

## Layout

Mobile: page full width, band, dock.  
Desktop: page in stage, character remains in context rail.

## Anti-patterns

Two-column tiny split on a phone. Highlight color as the only citation cue.
