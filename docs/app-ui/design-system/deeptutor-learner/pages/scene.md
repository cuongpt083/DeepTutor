# Page — Scene

Default study room. Character owns the middle.

## Emphasis

- Caption ≤ 2 lines under the character.
- Band mounts only when `choices.length > 0`.
- Context chips in the rail (topic / page / time), not a toolbar of tools.

## Motion

Band fade 240ms. No character bounce on every token of TTS.

## Anti-patterns

Message list. Composer. Mode tabs (Chat / Quiz / Solve).
